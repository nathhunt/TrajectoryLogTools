# Version and support

## Which version you have

The version is in the title bar of each app (for example *Trajectory Log Tools 1.0.0-beta*), and on the
line at the bottom of the window with the build it came from (for example *Version 1.0.0-beta+aeaf93d*).
The error log records it too.

This guide is for version **1.0.0-beta**.
